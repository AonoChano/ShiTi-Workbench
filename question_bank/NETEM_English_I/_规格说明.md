# 考研英语一 · 试卷 JSON 规格（spec_version 1.1）

本目录（`shiti-workbench/question_bank/NETEM_English_I/`）存放**逐份试卷**的 JSON 文件：每年一份，文件名 `<年份>.json`（如 `2000.json`），UTF-8 无 BOM、LF 换行。由 `TestPaper/<年份>.md` 转换而来。

**自动识别**：拾题服务启动时及每 5 秒扫描本目录（以及 `question_bank/` 下其他科目子目录）；校验零错误的文件自动建卷入库，文件内容修订会自动生成新题目版本（已答过的练习使用旧快照，不受影响），校验出错的文件只记录错误清单、不影响已入库内容。文件名以 `_` 开头的是文档/示例，不导入。其他学科以后各自建子目录（如 `question_bank/NETEM_English_II/`）。

---

## 一、转换完成后必须自检

```bash
cd C:\Users\CYcha\Documents\考研英语\shiti-workbench
npm run check-json -- "C:\Users\CYcha\Documents\考研英语\TestPaperJSON\<年份>.json"
```

- **退出码 0（零错误）**才算完成；`[警告]` 允许保留，但必须在 `meta.notes` 里逐条说明原因。
- 不确定答案时**宁可把 `answer_key` 设为 null（产生警告）**，绝不编造答案——错答案会直接判错学生。
- 严禁发明本规格之外的字段（会报 `UNKNOWN_FIELD` 错误）。`spec_version` 只能是 `"1.1"`。

## 二、顶层结构

```json
{
  "spec_version": "1.1",
  "meta":   { …试卷级元数据，见第三节… },
  "set":    { "title": "2010年考研英语（一）真题" },
  "sections":  [ …大题声明（章节扉页用），见第四节… ],
  "materials": [ …共享材料（完形原文/阅读文章/翻译原文），见第五节… ],
  "questions": [ …全部题目，见第六节… ]
}
```

## 三、meta 元数据（本规格的重点，务必填全）

| 字段 | 类型 | 要求 | 示例 |
|---|---|---|---|
| `year` | 整数 | **必填**，1980–2100 | `2010` |
| `paper` | 字符串 | **必填**，卷种 | `"英语一"`（2010 年前统一卷写 `"英语统考卷"`） |
| `title` | 字符串 | 强烈建议，原卷标题 | `"2010年全国硕士研究生入学统一考试英语（一）试题"` |
| `total_score_units` | 整数 | 建议；整卷满分 ×100，英语一固定 `10000` | `10000` |
| `duration_minutes` | 整数 | 建议；考试时长 180 | `180` |
| `source_file` | 字符串 | **必填**，来源 markdown 的相对路径 | `"TestPaper/2010.md"` |
| `source_images` | 字符串 | 有图片时必填，图片目录相对路径 | `"TestPaper/images/2010/"` |
| `converted_by` | 字符串 | 必填，转换执行者标识 | `"Claude（转换任务 2026-09-30）"` |
| `converted_at` | 字符串 | 必填，ISO 8601 带时区 | `"2026-09-30T14:00:00+08:00"` |
| `license_note` | 字符串 | 必填，授权说明 | `"个人学习使用"` |
| `notes` | 字符串 | 有警告/特殊情况时必填；如 OCR 缺失、图片无法还原、新题型具体形式等 | `""` |

规则：所有字符串 1–500 字符；`meta` 内同样**不许出现未知字段**。

## 四、sections 大题声明（章节扉页，强烈建议填写）

答题页**每进入一个大题，先显示一页扉页**：原卷 Part 编号 + 大题名 + Directions，用户点「开始作答」才进入题目（可随时在顶栏重看）。每个大题一个元素：

```json
{
  "id": "Section II · 阅读理解 Part A",
  "part": "Section II · Part A",
  "title": "阅读理解",
  "directions": ["Read the following five texts. Answer the questions below each text by choosing A, B, C or D. (50 points)"]
}
```

| 字段 | 说明 |
|---|---|
| `id` | **必填**，卷内唯一，1–100 字符；`materials[].section` 与 `questions[].section` 必须引用这里的 id（引用了未声明 id 会产生警告，该大题将没有扉页） |
| `part` | 原卷 Part/Section 编号标签，扉页大字显示，如 `"Section II · Part A"` |
| `title` | 大题中文名，如 `"阅读理解"`、`"英译汉"`、`"短文写作"` |
| `directions` | **照录原卷 Directions**，一行一条（≤12 行，每行 ≤4000 字符），含分值说明 |

规则：`id` 与 questions/materials 的 `section` 字段同名（建议直接照抄原卷 Section 标签）；sections 顺序即原卷大题顺序。

## 五、materials 共享材料

每份试卷的材料按"篇"组织：完形原文 1 篇、阅读 Text 1–4 各 1 篇、新题型短文 1 篇、翻译原文 1 段。每篇一个元素：

| 字段 | 说明 |
|---|---|
| `id` | 卷内唯一，建议 `cloze`、`reading-text1`、`newtype`、`translate` |
| `title` | 篇名，如 `"Text 1"`、`"Section I · 完形填空原文"` |
| `section` | 归属大题标签，与原卷一致：`"Section I · 完形填空"` / `"Section II · 阅读理解 Part A"` / `"Section II · 新题型 Part B"` / `"Section II · 翻译 Part C"` |
| `blocks` | 正文分段：每自然段一个 `{ "id": "p1", "type": "paragraph", "text": "…" }`，段落 id 依次 p1、p2… |
| `source_ref`（可选） | 原文位置说明 |

正文规范：
- 完形原文的空位写成 `__1__`（双下划线夹空号），第 1 空就是 `__1__`。
- 翻译原文的划线句在句首加 `【46】` 样式标记（题号用原卷编号 46–50）。
- 原文里的斜体、下划线等格式丢失即可，不要用 HTML。
- **不要**把图片 URL 或 Markdown 图片语法放进 text；作文配图无法文字还原时，在题干用文字描述画面，并在 `meta.source_images` 与题目 `source_ref` 指明原图位置。

## 六、questions 题目

通用字段：

| 字段 | 说明 |
|---|---|
| `id` | 卷内唯一、可读稳定：完形 `cloze-01`…`cloze-20`；阅读 `t1-q1`…；新题型 `nt-41`…；翻译 `tr-46`…；写作 `writing-a` / `writing-b` |
| `type` | `single_choice`（单选）或 `free_text`（翻译/写作）。新题型按空建模也是单选，见下 |
| `section` | 同材料 section 标签 |
| `material_id` | 关联材料 id；写作题没有材料则省略 |
| `stem` | 题干文本（见各题型规则）。**可用 `\n` 分行**：Directions、逐条要求各自一行；答题页左栏按行还原 |
| `images` | 可选，**题目配图**：相对 `TestPaper/` 目录的 POSIX 相对路径数组（1–10 项），如 `["images/2010/xxx.jpg"]`。禁止盘符、反斜杠、绝对路径、`..`。看图/图表作文必填，系统在答题页左栏直接显示图片 |
| `answer_key` | 见下；**客观题必填** |
| `explanation` | 解析，没有就省略（产生警告） |
| `max_score_units` | 分值 ×100，见分值表 |
| `source_ref` | 可选，原卷位置（如 `"Text 1 第2段"`、`"第46句"`） |
| `tags` | 可选，如 `["完形填空"]` |

### 题型映射（新旧考卷 → type 字段，1986–2025 全覆盖）

| 原卷题型（年代） | `type` | 建模说明 |
|---|---|---|
| 完形填空/英语知识运用（1991–） | `single_choice` | 材料含 `__N__` 空位，每空一题，stem 写 `"第 N 空："` |
| 语法结构与词汇单选（1986–1990 等） | `single_choice` | 无材料，stem 放完整句子/句子填空，照录四个选项 |
| 阅读理解 Part A（含早年） | `single_choice` | 每篇 Text 一个材料 |
| 新题型 7选5/排序/小标题（2005–） | `single_choice` | 每空一题，同一组选项每题重复给出（见第 6 条旧规则示例） |
| 英译汉 Part C（1991–） | `free_text` | 材料为整段原文（含 `【N】` 标记），stem 只放划线句英文原文 |
| 汉译英（1986–1990 等） | `free_text` | 材料放中文段落说明，stem 放要译的中文句子 |
| 短文改错（部分年份） | `free_text` | 材料放原文（逐行编号），stem 写明"找出并改正本行错误"；答案 reference_text 写正确形式 |
| 应用文/大作文（1991–；早年缩写/命题作文同） | `free_text` | Directions 用 `\n` 分行放 stem；看图/图表作文必填 `images` |

系统题型能力：`single_choice`（单选）、`multiple_choice`（多选，考研英语一暂未使用）、`true_false`（判断，同上）、`fill_blank`（填空，可多空并按空判分）、`free_text`（主观，按参考答案交外部 AI/人工评阅）。做题界面已按题型适配：选择类点击选项（数字键快捷），填空/主观类左侧题目右侧作答区。

### 分值表（英语一，max_score_units = 分数 × 100）

| 大题 | 题数 | 每题 max_score_units |
|---|---|---|
| 完形填空 | 20 空 | 50（0.5 分） |
| 阅读理解 Part A | 20 题 | 200（2 分） |
| 新题型 Part B | 5 空 | 200（2 分） |
| 翻译 Part C | 5 句 | 200（2 分） |
| 小作文 Part A | 1 题 | 1000（10 分） |
| 大作文 Part B | 1 题 | 2000（20 分） |

### 各题型转换规则

1. **完形填空**：材料 = 原文（含 `__N__` 空位）。每空一个 `single_choice`，`stem` 写 `"第 N 空："`（原文语境在材料里，不要把整段复制进题干）；选项 id 如 `c1-a`…`c1-d`；`answer_key: { "selected_option_ids": ["c1-c"] }`。
2. **阅读理解**：每篇 Text 一个材料；每题 `stem` 用完整题干原句；选项完整照录；`answer_key` 必填。
3. **新题型**（三种形式都建模为"每空一个单选"）：
   - 7选5/5选5：材料 = 短文（空位写 `__41__`）；每空一题，`stem` = `"第 41 空：从下列句子中选出填入本空的选项"`；**每题重复给出同一组选项**（选项 id 相同，如 `nt-a`…`nt-g`，文本为原卷 A–G 句）。
   - 排序题：`stem` = `"第 41 空：本空应填入的段落是"`；选项为 A–F 各段首句摘要（id `nt-a`…）。
   - 小标题匹配：选项为各小标题。
   - 在 `meta.notes` 写明该年新题型的具体形式。
4. **翻译**：材料 = 整段原文（含 `【46】` 标记）。5 个 `free_text`：`stem` = 划线句英文原文（**不要**再复制"将下面的英语句子翻译成汉语"指令——那是材料/左栏职责，也不要带 `【46】` 前缀，题号由系统显示）；`answer_key: { "reference_text": "参考译文…" }`（无可靠参考译文时 `answer_key: null`，会按待评处理）。
5. **写作**：两个 `free_text`，无 `material_id`。`stem` 放完整 Directions，用 `\n` 分行（情景说明一行、要求 1) 2) 3) 各一行、字数要求一行）；**看图/图表作文必须填 `images`**（原题图片相对 TestPaper 的路径），并在 stem 里客观补一句画面文字描述（当图片无法打开时用户仍可理解题意），不要把"原图见 …"路径文字混进题干；`answer_key: { "reference_text": "范文…" }`，无范文则 `null`。小作文 `max_score_units: 1000`，大作文 `2000`。系统会为 `free_text` 且满分 ≥ 10 分的题（即作文）自动提供标题输入栏，用户标题合并存储在作答文本首段，无需额外字段。
6. **判断题/填空题**本卷不使用（考研英语一没有），列出仅供系统完整性。

### answer_key 形态速查

```json
{ "selected_option_ids": ["t1-q3-b"] }          // 单选：恰好一个选项 id
{ "reference_text": "参考译文/范文全文" }          // 自由文本：参考答案（可省略）
null                                             // 无可靠答案 → 该题待评（产生警告）
```

## 七、完成定义（DoD）

1. `npm run check-json` 退出码 0，警告已在 `meta.notes` 说明；
2. `meta` 十一个字段按上表填写（`year/paper/source_file/converted_by/converted_at/license_note` 缺一不可）；
3. 题数与原卷一致（早年卷型与 2010 后不同，按原卷实际，并在 notes 说明）；
4. 文件命名 `<年份>.json` 放入本目录即告完成——服务会自动识别入库，无需任何手动导入操作；若服务未启动，下次启动时自动补扫。
