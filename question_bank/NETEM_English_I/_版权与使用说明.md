# 版权与使用说明

本目录（`question_bank/NETEM_English_I/`）收录的是**全国硕士研究生招生考试英语（一）历年真题**的机器可读转录版本。使用前请了解以下边界。

## 内容权利

- 考研试题的著作权归**教育部教育考试院及命题机构**所有。本目录中的 JSON 文件是对公开真题的个人学习用途转录与结构化标注，**不改变内容的著作权归属**。
- 各试卷 JSON 的 `meta.license_note` 字段统一标注为"个人学习使用"。
- 答案与解析部分：客观题答案来自公开渠道的官方参考答案；主观题（翻译参考译文、写作范文）为通用备考资料中广泛流传的参考版本，并经人工核对，**不代表官方发布文本**。
- 个别试卷存在来源缺陷（如原文段落缺失、OCR 需修复），处理方式与判断均记录在对应文件的 `meta.notes` 字段中，可追溯。

## 允许的用途

- 个人备考学习、练习与复盘
- 本地部署本工作台供自己使用

## 不允许的用途

- 任何形式的商用、售卖、付费分发
- 大规模再分发或转载题库内容（含整目录搬运到其他公开渠道）
- 移除本说明文件或将题库内容声明为自有版权

## 文件约定

- `<年份>.json` 为试卷数据文件，放入本目录后会被工作台自动扫描入库
- **下划线开头**的文件（`_规格说明.md`、`_版权与使用说明.md` 等）是规格与说明文档，**不参与入库**
- 试卷配图位于 `TestPaper/images/<年份>/`（仓库外），由 JSON 内的相对路径引用
