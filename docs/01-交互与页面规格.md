# 01 · 交互与页面规格

版本 1.0。本文中的 MUST/必须属于验收要求；推荐项不能代替必需行为。视觉尺寸在 `design/README.md`；本文优先于生成图片。

## 1. 页面路由与可达性

路由是建议的产品 URL 契约，接口 URL 另见数据规格。

| 路由 | 页面 | 入口 | 主要动作 |
|---|---|---|---|
| `/` | 学习台 | 启动默认 | 继续练习、开始练习、复习到期项 |
| `/library` | 题库 | 主导航 | 搜索、筛选、导入、创建题集 |
| `/library/import` | 导入向导 | 题库工具栏 | 解析、校验、确认发布 |
| `/library/sets/:setId` | 题集详情 | 列表 | 检查题目、开始练习、编辑版本 |
| `/library/questions/:questionId` | 题目编辑/版本 | 题库详情 | 草稿、预览、发布、归档 |
| `/practice/new` | 配置练习 | 学习台/题集 | 模式、范围、题序、开始 |
| `/practice/:attemptId` | 答题 | 开始/继续 | 保存、标记、导航、提交 |
| `/attempts` | 练习记录 | 主导航 | 筛选、查看、继续、归档 |
| `/attempts/:attemptId/report` | 复盘报告 | 提交后/记录 | 查看证据、评分、导出、复习 |
| `/review` | 错题复习 | 主导航 | 选任务、重做、改期 |
| `/settings` | 设置 | 主导航 | 工作区、偏好、备份、安全、AI |

URL 使用不泄露个人信息的稳定 ID；报告锚点 `#q-q03` 可以复制。刷新/直接访问有效 URL 应恢复对应状态；非法或无权限 ID 显示“找不到这条记录”，不泄露本机路径。未开始/已提交的 Attempt 访问答题页分别进入配置确认/报告；不重启计时。

## 2. 全局布局和组件契约

### 2.1 布局

- 桌面：宽度 ≥1200px，左导航 200px，主区侧距 32px；答题页材料/问题默认 55:45，双方最小可读宽度 340px。
- 中屏：768–1199px，导航折为 64px 图标栏；空间不足时材料/问题改标签切换，不挤到横向滚动。
- 手机：<768px，主区侧距 16px；普通页采用底部四项入口“学习台/题库/记录/复习”，设置从顶部菜单进入；答题页隐藏底部全局导航，替换为题目操作栏。
- 文章最大行宽约 70–80 个英文字符；英文正文初始 18px，行高 1.75；用户可调 16–24px。
- 手机英文正文不小于 17px，控件文字不小于 14px；题干与答案不能靠缩小字体硬塞。
- 粘性底栏遵循安全区，正文有相应底部留白；软键盘出现时不要覆盖正在输入的文本。

### 2.2 组件状态

按钮包含 default、hover、focus-visible、pressed、disabled、loading。loading 不抖动宽度，显示具体动作如“正在提交…”。禁用控件必须在附近解释原因。

列表包含 skeleton、empty、filtered-empty、loaded、error、load-more；搜索结果为空提供“清除筛选”，不能与未导入题库混用文案。

对话框包含标题、结果解释、取消、主要动作。打开时聚焦标题或安全操作，焦点限制在框内，Escape 通常关闭，关闭后焦点回原触发点。不可逆动作不得把 Enter 默认绑定为执行。

Toast 成功停留 4 秒，错误和需要操作的信息持久显示；屏幕阅读使用适当 `aria-live`，不每秒播报计时器。

### 2.3 导航和快捷键

默认提供可发现的快捷键帮助。无文本输入焦点、无弹窗、未开启中文输入法组合输入时，`1–9` 选择当前单选选项，左右方向键在显式启用的题目导航区域切题；不全局抢占阅读方向键。

`Alt+N` / `Alt+P` 可作为可配置下一题/上一题快捷键；若浏览器或系统冲突，用户可关闭。`Ctrl+Enter` 只打开交卷确认，不直接提交。Tab 顺序必须与视觉阅读一致。

## 3. P0 首次启动

### 屏幕目的

让用户知道数据在哪里，并能立即开始。只展示两个步骤：确认本地工作区 → 导入题目或体验原创样本。

### 行为

1. 后端健康检查通过后显示工作区名称、路径的安全缩略表达、可用空间及“打开数据位置”说明。浏览器版不承诺能直接打开系统文件夹，可复制路径。
2. 告知“数据保存在此电脑；清理浏览器不会删除已保存记录，但会影响未同步草稿”。
3. 样本必须显著标注“演示”，使用独立演示题集；不能产生看似用户真实历史的统计。
4. AI 配置不是必经步骤，不弹出索要 API Key 的欢迎页。
5. 服务不可达时展示启动/重连说明；只读浏览器草稿恢复页可用，但不能假装数据库已连上。

## 4. P01 学习台

### 信息优先级

第一优先是未完成练习，其次是今日复习，第三是最近报告；不以一排抽象总数占据首屏。

### 内容

- “继续练习”显示题集、已答/总题、保存时间、模式；严格限时已到期显示“查看自动交卷结果”，不是“继续”。
- “开始练习”打开配置页；若完全没有题目，按钮为“导入第一份题目”。
- 今日复习按到期时间展示最多 5 项，提供“查看全部”；统计去重后的 ReviewItem 数。
- 最近三份报告显示已判分数、待评数量、是否已导出；没有待评时不占位显示零。
- 多个进行中 Attempt 按最后活动排列，不静默替换旧练习；新建练习提示已有练习但允许训练模式多份共存。

### 空/失败

无记录时用一个清晰引导，不显示伪造周趋势；加载失败保留导航，提供只重试该区的按钮。

## 5. P02 题库与题集详情

### 列表

标题、题数、已提供答案题数、题型、来源、更新时间、版本状态；题集表格支持按标题/更新时间排序，默认更新时间降序、ID 为稳定次排序。

搜索范围：标题、题干、标签；默认不搜索隐藏答案内容。输入防抖 250ms，保留查询于 URL 的普通搜索参数；中英文均可。P0 数据量小可采用规范化 LIKE，后续 FTS 是优化，不要让分词依赖阻塞使用。

标签筛选同组 OR、跨组 AND，UI 写明；“已归档”默认隐藏。批量选择跨分页不默认全选所有结果，必须有明确范围。

### 题集详情

显示共享材料、题目列表、顺序、每题分值、答案状态。预览模式明确“题库预览，包含答案”，不能误以为正在考试。编辑会生成草稿；发布前显示版本变更摘要及“已进行的练习不会改变”。

开始练习按钮在至少有一道已发布题时可用；没有答案的题可练，但启动前提示其无法自动判分。

### 归档

确认文案：“归档后不再出现在默认题库中，历史练习和报告保持可用。”支持撤销归档。P0 不提供物理删除历史题目版本。

## 6. P03 导入向导

### 步骤 1：选择与声明

支持拖放、文件选择和手工创建；给出格式、上限、模板下载。用户选择“我有权用于个人学习”，该确认不代表平台验证了版权。

初始上限：JSON/Markdown 10MB、PDF 50MB/300页、单图 15MB、每题集 500题；超过明确拒绝，不无限加载。

### 步骤 2：预览与校验

左侧来源预览，右侧结构化字段；每条错误绑定题目与字段。计数固定为“可导入 N / 需修正 M / 未选择 K”。

错误：重复题目 ID、选项 ID 重复、正确答案引用不存在、分值无效、未声明题型、空题干、附件不存在。警告：未提供答案、疑似重复内容、解析缺失、来源不完整。

**红色错误阻止该候选发布；黄色警告允许用户明确确认后发布。** AI/OCR 置信度不等于字段已正确。没有 OCR 时 PDF 原图仍可浏览并手工建立题目；不显示假进度条。

### 步骤 3：确认发布

显示将创建的题集、题数、无答案数和附件大小。未修正候选必须取消选择，不自动丢弃。点击“导入 N 题”只创建一个幂等事务。失败保留草稿并说明重试不会重复建题。

取消上传可清理 staging 临时资产；已发布引用不受影响。源文件被移走后，已复制到工作区的资产仍然可用。

## 7. P04 练习配置

字段：题集、题目选择、题数、题序（原顺序/随机）、选项顺序（默认不随机）、训练/严格限时、限时分钟数、是否记录可选思路、字号。

- 默认沿用题集顺序；随机选择保存 seed 和实际顺序。
- 含“以上全部”等位置语义的选项不得默认随机，编辑者须标为允许重排才能开启。
- 组合题按材料组抽取，除非用户明确切到单题复习，不随机拆散共享阅读材料。
- 限时为 1–360 分钟正整数，启动前显示“休眠和离开页面不会暂停”。
- “开始练习”创建快照、发放写租约、开启计时是一个明确动作；进入配置页不计时。
- 题目版本在启动事务时确定，若刚被归档/删除则返回可理解冲突并重新确认，而不是开启空卷。

## 8. P05 答题工作台

### 8.1 顶栏

题集/材料名称、模式、保存状态、计时器、暂停（仅训练）、交卷。主标题不过大；计时可减少视觉显著度，但严格模式剩余 5 分钟/1 分钟给予一次文字提示，不连续闪烁。

保存状态固定为：

| 状态 | 文案 | 可做什么 |
|---|---|---|
| 本地正在落队列 | 正在记录… | 不应超过正常单次交互周期 |
| 浏览器已记录，后端未确认 | 已暂存浏览器，正在同步… | 可继续，保留黄色标识 |
| 后端事务已确认 | 已保存到本机 · HH:mm:ss | 可放心刷新 |
| 网络/服务失败 | 尚有 N 处未同步，草稿保留在此浏览器 | 重试、复制草稿 |
| 本地与后端均不能保存 | 无法保存，请先复制当前答案 | 停止新增输入，避免虚假安全感 |
| 其他标签已接管 | 此页只读，另一页面正在作答 | 查看/申请接管 |

### 8.2 材料区

显示材料标题、来源短标、段落编号、正文和图片；正文不含答案解析字段。选中文本后出现键盘也可触发的标注菜单：“高亮”“记录为依据”“摘录词汇（P1）”。P0 高亮保存材料版本、段落 ID、原文片段及起止偏移；偏移失效则显示“原文位置已变化”，禁止标错到其他文本。

P0 标注只使用已固化材料快照；原题更新不改变练习材料。复制原文不做防复制限制。

### 8.3 问题区

题号、题型、分值、标记按钮、题干、答案控件；下方“把握程度（可选）”“我的思路（可选）”。选项在交卷前只显示选择态，不显示绿色正确或红色错误。

单选点击新选项替换旧选项；取消单选通过“清空本题作答”明确按钮，不用再次点击同一项实现隐蔽清空。多选显示“多选，必须完整选对”规则说明。填空每空有标签；自由文本显示字数/字符数口径，不做强制 AI 润色。

思路在提交后锁定为原始自述，复盘笔记另开输入区。输入法 composition 期间不触发快捷键、不截断文本、不将半个组合字保存为最终版本。

### 8.4 答题卡

题号按钮用形状、边框、短标签共同表达：未答、已答、当前、标记。辅助文本如“第3题，已答，当前”。组合题按材料分组。顶部显示已答数，主观题有非空文字算已答，不等于已判。

点击题号先持久化当前浏览器草稿再切题；不要求等待后端网络，否则断网无法导航。切换成功后滚动到新题标题并管理焦点；文章区保留滚动位置。

### 8.5 训练暂停

暂停先保存，然后进入遮罩；暂停期间不显示可继续阅读的试题正文，防止有效时间统计失真。继续后恢复题号和滚动位置。服务端确认暂停才从训练活动区间移除时间；中断期间的时间质量按计时契约记录。

### 8.6 严格限时

页面定时器仅显示，服务端截止为权威。到期后立即只读并提示“正在封存已保存作答”；如果服务断开，保留本地草稿但显示“等待本机服务确认交卷”，不能显示已提交成功。迟到草稿可另行导出或转为训练，不改变正式卷。

## 9. P06 交卷确认

对话框显示：已答 X/N、未答题号、标记待查题号、待同步数、客观自动判分题数、主观/无答案待评题数。

- 训练模式有待同步项时禁用正式交卷，提供重试和复制未保存答案。
- 用户点“仍然交卷”只适用于已同步但存在未答，不允许绕过未保存风险。
- 严格模式到期为系统提交，不要求用户确认；截止前主动提交仍要求全部当前草稿收到服务端确认。
- 提交动作使用同一幂等键反复重试。等待时禁止再次编辑，但用户可查看作答，不出现无限遮罩。
- 后端提交成功但前端超时，重连查询 Attempt 状态；若已提交跳报告，不能新建另一次提交。
- 提交成功后焦点落在“本次练习已交卷”；报告生成中显示真实阶段，不反复转圈假装仍在保存答案。

## 10. P07 复盘报告页

### 10.1 页面结构

顶部题集与练习时间、训练/模拟标识、报告版本；右侧“复制 Agent 指令”为主动作，旁边“导出 Markdown”、复盘目录和版本选择。标题下显示文件状态条：等待填写、正在校验、已读取修订N、校验失败保留旧版、文件缺失、上下文已过期。状态来自后端，不能猜测 Agent 正在思考。完整文件交互见[外部Agent文件协议](05-外部Agent文件协议.md)。

摘要显示已判得分/已判满分、整卷满分（有待评时突出）、正确/错误/未答/待评、有效时长及时间质量。接着显示本次最需要回访的题，而不是先给无证据的 AI 总评。

左侧章节导航可折叠；主区逐题对照。每题内容包含：原题、我的答案、标准答案与来源、确定性结果、原始思路与把握程度、支持证据、复盘笔记、行动项。

### 10.2 信息标识

用不同文本标签标明“事实记录”“用户自述”“规则归纳”“AI 建议·待确认”“已确认笔记”。AI 文本即使用户确认仍记录其来源，不变成官方解析。

错误原因选择默认空；用户可多选/自定义，保存的是复盘记录，不改原始思路。猜对、正确但不确定单列为“不稳定项”。

### 10.3 待评与改分

主观题显示“待评 / 满分 X”，提供输入得分、Rubric、评语和来源。保存前校验范围、必填原因、评分来源。已存在评分时明确“将创建评分版本 2，旧报告保留”。用户不能编辑系统客观判分值而不留下人工覆盖记录。

### 10.4 版本过期

报告顶部检测当前评分/复盘是否新于报告快照，显示“有新的评分或笔记，可生成新版报告”。旧版仍可下载；系统不替换用户刚复制的内容。生成新版先选择最新输入版本，再固定任务输入。

### 10.5 生成错误

如果报告失败，仍显示结构化结果和逐题事实；可重试相同输入的生成任务。明确区分“交卷成功，报告生成失败”与“尚未确认交卷”，两者不能共用“操作失败”。

## 11. P08 导出抽屉

先选用途：完整复盘/隐私精简；再显示字段选择：原文、题干选项、标准答案、思路、时间轨迹、个人标签、AI 建议、附件。

不能关闭报告身份、口径、题目结果与省略说明。若去掉标准答案或原文，预览中出现“外部 AI 无法核验缺失上下文”。逐题内容不静默截断。

导出按钮文案“下载 .md”；这是本地浏览器下载动作，不保证用户下载目录可写，失败时可复制已生成文本。“复制 Agent 指令”是不同动作，只复制本机文件协作指令，不上传任何内容。

P0 导出 ZIP 需确认资产授权和大小；无附件时说明“本报告不含附件”。安全文件名不包含冒号、斜杠或原始个人路径。

## 12. P09 外部 Agent 文件复盘

P0 工作流：交卷自动准备 context.md/review.md/state.json → 用户复制 Agent 指令 → 在外部 CC/Harness 要求分析 → Agent 修改 review.md → 后端校验 → 网页自动读取显示。不是手动粘贴回复，也不内置模型调用。

同步条显示“等待填写/正在校验/已读取修订N/校验失败保留旧版/文件缺失/上下文已过期”。显示实际文件名和更新时间，不猜测 Agent 是否正在推理。错误能展开到具体行、字段与证据ID，并有“重新读取”。

更新时保留当前题号、展开、滚动和选择；用户正在读的块显示可点击更新提示。界面分析正文在P0只读；修改请让Agent编辑文件，个人补充笔记另存，不形成网页/文件双写冲突。

外部建议通过校验即显示，但只有用户点击“采纳到复习计划”才建立任务。Agent不能凭正文改变分数或确认状态。文件格式、乐观并发、监听兜底和完整验收见[外部Agent文件协议](05-外部Agent文件协议.md)。

## 13. P10 错题复习

页头显示到期、未来、已暂停三个视图。默认“到期”，支持来源题集、原因、题型筛选。列表项显示到期日、关注类型、最近一次结果、复习次数、材料标题，但不显示正确答案。

“开始重做”创建一个新的训练 Attempt，并关联被选 ReviewItem。复习流程中不能提前展开旧解析。完成后才进入新旧对照，展示“同一题不同练习”的来源和版本，避免不同版本题目得分直接相减。

“稍后复习”可选明天/3天后/日期，记录人工改期；不会直接标为掌握。“暂停关注”可恢复；错误历史保留。手动“已掌握”是用户声明，与测试通过分开。

无到期任务时显示下次日期和“选择其他题目”，不制造红色紧迫感、连续打卡羞辱或惩罚性文案。

## 14. P11 设置与数据管理

### 外观

系统/浅色/深色；字体、字号、段落宽度、减少动效；即时预览，偏好保存到本地后端，浏览器缓存只是加速。

### 工作区

说明数据位置、数据库大小、资产大小、上次成功备份时间；迁移数据目录属于高风险功能，P0 可只提供备份恢复，不实现拖动文件夹。

### 备份

“创建备份”显示包含范围与是否加密（P0 未实现加密必须明确显示“未加密”）。过程为一致性快照→资产复制→摘要核验→下载/受控保存；取消不会删除原数据。

### 恢复

选择备份→校验→显示版本、题数、练习数、资产完整性→创建当前数据备份→用户确认→恢复到新工作区→核验→切换。不能原地覆盖当前工作区。

### 外部 Agent 文件

显示复盘目录、协议版本、最近文件校验状态、重新读取和复制操作说明。不提供模型选择或密钥输入。首次说明：外部Agent可能向其供应商发送读取到的上下文，用户应自行选择权限和可信工具。网页不启动Agent，也不控制其费用。

## 15. 关键错误文案

| 场景 | 文案 | 下一步 |
|---|---|---|
| 后端离线 | 尚有 2 处修改未同步，已暂存在此浏览器 | 重试同步 / 复制草稿 |
| 磁盘满 | 本机空间不足，刚才的修改尚未保存到工作区 | 复制草稿 / 清理空间后重试 |
| 修订冲突 | 这条记录已在另一个页面更新 | 查看最新内容 / 确认接管 |
| 导入答案无效 | 第 3 题的答案引用了不存在的选项 E | 定位答案字段 |
| 缺标准答案 | 未提供可核验答案，本题暂不自动判分 | 添加答案版本 / 保持待评 |
| 报告任务失败 | 作答已保存并交卷，报告暂未生成 | 查看结构化结果 / 重试生成 |
| AI 不可用 | AI 分析未完成，作答与基础报告不受影响 | 稍后重试 / 导出手工复盘 |
| 备份校验失败 | 备份中有附件摘要不匹配，未修改当前工作区 | 查看缺失清单 / 选择其他备份 |
| 到期时断开 | 已停止作答，等待本机服务确认交卷 | 重连 / 保存迟到草稿副本 |

## 16. 交互验收最短路径

1. 仅键盘导入原创样本，启动训练，选答案、记录思路、暂停继续、交卷。
2. 刷新并恢复同一题、同一答案和标记；未同步状态不能显示已保存到本机。
3. 在 390px 宽度完成阅读、切换题目、打开答题卡和导出，不出现页面水平滚动。
4. 未答确认能准确跳回具体题号；退出后焦点、正文滚动位置正确。
5. 报告数字与导出一致；复制证据锚点后能定位到对应段落或题。
6. AI 不配置、网络断开时，除明确依赖网络的可选功能外，核心闭环完成。
7. 让用户第一次接触页面时不需要阅读开发文档即可理解保存状态、待评、报告版本。
