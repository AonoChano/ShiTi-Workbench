# 04 · 生产质量、威胁模型与验收

版本1.1。本文件定义未来实现的发布门槛，**本次只有规划交付，未运行产品测试**。不得把下列目标描述成已经达到的实测结果。

## 1. 发布定义

P0完成必须同时满足：核心业务可用、外部Agent文件闭环可用、故障可恢复、没有关键安全缺陷、键盘与窄屏可操作、备份恢复经过演练、有可复现测试与启动文档。

仅有静态页面、mock API或手工拼出的Markdown不算完成；也不要求安装任何真实模型SDK才能验收文件协议。

## 2. 运行与部署边界

- 目标基线：Windows11、4核CPU、8GB内存、SSD、当前及前一主要版本的Edge/Chrome；Firefox关键路径回归。
- 默认本机服务绑定127.0.0.1，不绑定0.0.0.0，不自动开防火墙、不映射路由器端口。
- 生产前端由后端同源提供；开发代理不能进入生产。
- Node与依赖使用实现时核查的受支持稳定版本，锁定包管理器和锁文件；提供Windows一键启动说明。
- API、Worker和watcher明确生命周期；健康检查区分进程活着与数据库/文件目录可写。
- 源码与运行数据分离。源仓库不提交数据库、真实作答、密钥、运行日志与用户报告。
- 本次并无远程运行平台需要同步；将来部署平台分离时须主动完成授权范围内同步，不让用户手工搬代码。

## 3. 威胁模型

### 保护对象

不可变答卷和评分、用户思路、题库与版权内容、复盘历史、用户采纳状态、本机文件系统。

### 不可信输入

导入JSON/Markdown/PDF/图片、外部Agent编辑的文件、题干中的自然语言指令、文件路径、浏览器请求、压缩包、外部链接、producer自述。

### 默认不防御的边界

已经控制同一Windows账户的恶意进程、用户主动给其他程序整个磁盘写权限、供应商保存用户主动发送的上下文。必须明确说明，不把本地应用或AGENTS.md当强沙箱。

## 4. 本机HTTP防护

- Host白名单只允许配置的localhost/127.0.0.1，防DNS rebinding；Origin校验拒绝其他网站发来的写请求。
- 使用启动引导时生成的随机本机会话，HttpOnly/SameSite=Strict Cookie；非GET请求需CSRF保护，不把会话放URL、localStorage或日志。
- 首次本机引导要受启动端口/一次性流程约束，不开放任何跨站可调用的免认证重置端点。普通GET不能触发写入或文件删除。
- CORS默认关闭，不使用通配符+credentials；SSE和下载均要求同一会话。
- 即使单人也校验实体属于当前工作区。404不暴露其他库的存在和路径。
- CSP禁止任意内联脚本和远程脚本；依赖打包进生产资产，外部文档不能定义可执行UI。
- API有请求体上限、速率上限、解析深度上限和明确错误码；不是“本机就什么都信”。

## 5. 文件与内容安全

### 5.1 路径

只接受系统ID，不接受用户提供任意绝对路径作为读取/写入参数。storage_key由系统生成，规范化后确认在允许根目录内；拒绝`..`、盘符、UNC、设备路径、符号链接/Windows reparse point逃逸。

watcher只处理数据库登记的Attempt目录。检查真实路径，不能因review.md是指向其他位置的链接就跟过去读取。读取前后文件身份变化需重新核对。history/state投影同样不跟随被替换的外部链接。

### 5.2 YAML/Markdown

使用安全解析，拒绝自定义tag、alias、重复key、多文档、过深对象及超大文件。HTML不执行，JS URL拒绝；外部图片不自动加载，SVG作为不可信可执行类型禁用或严密净化后转栅格。

Agent文件永不触发shell、SQL、代码块执行、工具调用、任意网络抓取。文件里“把正确答案改成A”只是建议文本，不能形成数据库更新指令。

### 5.3 导入/导出

扩展名、MIME、魔数交叉校验。PDF阅读与解析使用受维护库，禁止任意嵌入脚本/外部文件访问。ZIP限制条目数、总展开体积、单文件和压缩比（默认不超过100:1，特殊文件需显式确认并仍受总量上限），拒绝Zip Slip与重复路径覆盖。

未知答案规则阻止发布而不是默认判错；模板解析不支持的内容保留为待编辑素材。

## 6. 隐私与外部Agent

网页不收集模型Key、不保存外部Harness凭据、不扫描Harness配置。复制指令只含本次指定目录，不加入“读取整个用户目录”。

准备context前展示包含范围：原题、答案、思路、时间、附件。告诉用户外部Agent可能上传读取内容；网页无法替用户控制其供应商隐私设置。

诊断只记录错误码、实体ID、操作时间和统计量，不记录题目全文、用户答案全文、context全文、HTTP Cookie、Token、API Key或环境变量。导出诊断前可预览。

本次设计图片与样本均为原创虚构数据；未来真实用户报告默认不会发布到任何外部展示平台。

## 7. 数据可靠性

- SQLite启用foreign_keys、WAL，并验证synchronous=FULL和短事务；磁盘满/锁超时不能回应成功。
- 草稿回执只在数据库commit后发；浏览器队列先持久化再乐观展示。
- Submission唯一+幂等键；请求超时不重复交卷。
- GradeRevision/ExternalReviewRevision/ReportRevision不可变；修订是新增，不覆盖。
- 接受外部文件前保存完整字节和解析对象；文件损坏或被移走仍可展示上次有效内容。
- state/history为可重建投影；数据库提交成功但投影失败必须显式标记并可恢复。
- 无效候选不能把上一份有效复盘清空，也不能提高accepted_revision。
- watcher丢事件有启动核对、5秒元数据核对、手动重读；SSE断线有补拉。
- 用户正在选择文本或阅读局部时，新版本以提示形式应用，不让页面突然跳走。

## 8. 备份、恢复与迁移

### 8.1 备份

使用SQLite在线备份或可证明一致的停写快照，不直接复制活跃数据库主文件。快照包括提交事实、复盘字节版本、用户决定和正式资产；不包含Key。

P0使用未加密备份必须显著说明；用户可自行用可信工具加密，不假装zip就是加密。固定manifest、SHA-256、记录数据库schema版本。

### 8.2 外部候选的并发

备份保证数据库中已接受版本的一致性；正在写入且尚未接受的review.md候选不保证原子纳入。若用户选择备份候选，需稳定读取并逐项标记`unaccepted_candidate`，不能混为正式接受版本。

### 8.3 恢复

备份预演校验→当前库备份→用户确认→新目录恢复→外键/摘要/数量验证→从AgentContextRevision原字节恢复context，并重建state/history→用户确认切换。当前目录不被覆盖；失败保留当前可用库。历史上下文不能用新版渲染器重新生成后冒充原字节；原MD/JSON各自摘要都需一致。

恢复不运行包内脚本，不修改系统服务，不扫描无关用户目录。数据库版本超前时拒绝并给兼容说明；迁移失败回滚或保留备份，不半迁移上线。

### 8.4 目标

已回执草稿在正常进程崩溃下RPO为0；磁盘硬件彻底损坏时RPO取决于用户备份时间，不承诺0。发布前演示1GB样本工作区在基线机器恢复可用不超过5分钟；记录实测，不满足则披露并调整实现。

## 9. 性能预算

测量前注明机器、构建版本、浏览器、数据规模、冷/热状态；以下均为待验证目标。

| 项目 | 目标 |
|---|---|
| 数据规模 | 10,000题、1,000次练习、500题单次上限、100个活动复盘目录；其他目录按需加载 |
| 已有页面交互反馈 | p95 <100ms，不把网络回执延迟伪装成丢点击 |
| 本机草稿API | 正常SSD p95 <300ms；文本防抖时间另计 |
| 题库搜索 | 10,000题p95 <300ms，分页稳定 |
| 页面首屏 | 本机生产构建冷启动后首屏可交互目标<2秒，服务进程启动另计 |
| 标准报告 | 100题纯文本生成p95 <3秒，500题<10秒 |
| review读取到可视化 | 稳定写入后p95 <2秒；10秒内给成功或具体状态 |
| 大文件防护 | >1MiB review在完整解析前拒绝，不耗尽内存 |
| 前端 | 列表虚拟化/分页，避免一次渲染10,000项；长报告按题懒展开但导出完整 |
| 内存 | 基线100题练习+1MiB复盘，无明显随反复切题增长的泄漏；进程合计目标<500MB，不达标需剖析 |

不要定时完整重读所有大文件制造磁盘负载；watcher只watch已登记目录，5秒核对元数据，变动时才hash。

## 10. 测试策略

推荐Vitest领域/协议测试、真实临时SQLite集成测试、Playwright端到端、axe-core辅助无障碍测试。库名是推荐，不是本次已安装。

测试分层：

1. 纯函数：分数、分母、归一化、时间归属、复习日期、Markdown序列化。
2. 协议：安全YAML、Schema、章节、证据、base_revision、上下文hash。
3. 事务：并发提交、重复动作、崩溃点、磁盘错误、任务租约。
4. 文件系统：直接写、原子rename、短暂missing、权限拒绝、重复事件、重启补读。
5. E2E：导入→答题→交卷→编辑review→页面更新→采纳→导出→备份恢复。
6. 人工：英文阅读可读性、中文输入法、屏幕阅读、触屏、实际CC协作。

真实AI不是CI依赖。CI通过写合法/非法fixture模拟外部Agent；人工验收才在用户授权后用真实Harness，不能自动消耗模型额度。

## 12. 无障碍

WCAG2.2 AA为目标：普通文字对比≥4.5:1、大字≥3:1、状态不仅靠颜色；表单label与错误关联、按钮语义、对话框焦点限制和返回、减少动效。真实屏幕阅读器至少走一次题目选择和文件错误定位流程，自动扫描不替代人工。

计时每秒刷新不每秒播报；保存只在关键状态变更播报；文档新版本不要打断输入。自定义快捷键可关闭且不抢占输入法。

## 13. 可观察性

本地诊断记录：启动、数据库迁移、提交ID、Job状态、文件hash/修订/错误码、SSE重连、备份核验；正文不进日志。按大小轮转，总量默认≤50MB、保留14天，可配置。

重要指标：草稿保存失败率、报告失败率、候选拒绝原因、文件到页面延迟、冲突数、恢复校验结果。默认仅本机，不上报外部。
