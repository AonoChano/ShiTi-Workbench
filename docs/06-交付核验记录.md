## 3. 文档审查后修正的五项问题

1. **上下文与复盘并发：**接受候选的事务同时比较review版本、context身份/hash、ready状态和目标评分；人工改分立即标preparing，封住异步重建窗口。
2. **历史上下文权威：**补充AgentContextRevision，保存上下文原字节、双格式hash、生成版本和证据索引，历史恢复不依赖新版渲染器猜旧字节。
3. **系统投影被误改：**重启先核对已知摘要，不能先覆盖state再检测；外部修改保留并等待用户确认。
4. **MD/JSON事实不齐：**补齐JSON完整解析和时段事件，增加JSON自身摘要；两格式共享同一逻辑上下文契约。
5. **建议确认继承：**固定suggestion-hash-v1覆盖题目、证据、正文、检查标准和间隔；客户端hash不作权威，并提供测试向量。
