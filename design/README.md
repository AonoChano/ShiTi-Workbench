**产品：拾题 / Shiti Workbench。** 本目录只含设计素材、提示词和评审记录，所有图为AI生成的原创产品参考，不是运行中产品截图。

最终方向：冷白阅读工作台、精确的证据对照、低干扰蓝色交互。核心体验是外部Agent编辑review.md，网页显示已校验的内容，不是网页聊天。

### 2.2 字体

- 中文UI：`"Noto Sans SC", "Microsoft YaHei UI", "PingFang SC", sans-serif`。
- 英文阅读正文：`"Source Serif 4", "Georgia", "Noto Serif", serif`。
- 数字与路径：`"Cascadia Code", "Consolas", monospace`，数字启用tabular-nums。
- P0可用系统回退；需要指定字体时随应用离线打包并核查许可，不依赖联网Google Fonts才能阅读。

字号：页面标题24/32，区域标题18/26，正文16/26，英文材料18/31.5，辅助14/22，最小非必要说明12/18；手机正文至少17px。文章不要使用UI小字字号。

### 2.3 间距与形状

基础间距4/8/12/16/24/32/48；输入/按钮圆角8px，标签4px，主阅读面板10px。阴影仅用在弹层/浮动菜单，不给所有面板同等强阴影。

桌面导航200px；内容外距32px；中屏可折64px；手机外距16px。主按钮高度40px，触屏点击目标≥44px。细边框1px；焦点环2px并有2px间隙。

### 2.4 布局

桌面答题材料55%/问题45%，但最小可读宽度不足时主动切标签。报告优先摘要→文件同步→证据与分析→行动。首页先继续当前任务，不用无意义大数字卡片占满首屏。

渐变、玻璃拟态、营销插画、聊天头像、打卡金币均不属于产品视觉语言。证据P1/P2/P3、题号、来源文件与修订是真实信息，不作装饰编号。

## 3. 动效与状态

- 普通hover/展开120–180ms；减少动效设置下无位移动画。
- 保存条、文件错误、评分过期是持续状态，不用短Toast一闪而过。
- 新文件读取后保持滚动和当前题；正在选择文字时提示更新，不抢焦点。
- 读取中使用真实阶段文案，不给Agent推理过程编造百分比。
- 字段错误紧邻字段；危险操作有确认；未实现功能不画成可用按钮。

## 6. 图片已知偏差：实现时必须纠正

生成图不能代替数据契约。以下差异已在实际看图后识别，不要求开发照搬：

1. **导入页顶部“取消导入”被模型画成蓝色。** 实现必须用中性次级样式；主要动作应是修正/确认导入，不能诱导取消。
2. **导入页左侧原文/题目预览有示意性排版，未完整复刻Q3题干。** 真实预览必须来自来源文件，不允许补造段落或题目。右侧字段错误示意可采用。
3. **错题页顶部残留参考图的“用时12:34”。** 队列页不是正在练习，实施时删除计时器；仅具体Attempt计时。
4. 报告原图“修订3”用于表达迭代中的视觉状态，机器示例包是修订1；测试以state.json为准，不能把图片数字硬编码。
5. 报告图中“明天09-30”是基于演示日期09-29的建议，不是已建立任务。真实页面先显示“建议1天后”，用户确认后才定日期；“编辑计划”在未采纳时改为“调整建议”。
6. 错题队列图假设用户已经采纳四项，而报告/文件样本假设尚未采纳；这是流程的不同阶段，不是同一时刻的数据。
7. 首页“继续练习”与“最近复盘”是不同Attempt；不得允许同一个Attempt同时进行中又已提交。
8. 文字细部、图标形状与拼写以规格的真实字符串为准；原图不是文字OCR来源。进度条必须按真实比例绘制。

以上偏差不影响选样的布局用途。产品验收检查真实DOM、数据、键盘和状态，不能只做像素截图相似度。

## 7. 开发使用方法

1. 先读文件协议和交互规格，再打开对应最终PNG。
2. 建立Token与基础组件，不把PNG切片充当按钮/正文。
3. 先实现答题→交卷→外部文件更新→复盘的最小闭环。
4. 使用样本真实数字和字符串；UI中演示模式显著标识。
5. 补齐加载/无内容/文件错误/冲突/过期/暗色/键盘等未画出的状态，这些由文字规格规定。
6. 不因为图片没有某个安全提示或焦点环就省略它；不因为图片多了一个计时器就增加无意义功能。
